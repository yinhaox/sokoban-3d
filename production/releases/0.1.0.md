## Known issues

- **音效是占位级**：只有 7 个运行时合成的短提示音，音色与混音未按正式音效设计打磨（`src/audio/audio_director.gd:1-7`）。
- **遮挡柱/墙会半透明，偶尔像玻璃方块**：相机与玩家之间的墙柱淡出到 `occlusion_alpha` 0.12（`design/camera-and-presentation.md:95`），实现里透明墙面与 0.55 alpha 的顶盖同时可见（`src/game/board_builder.gd:39-41`）；`production/qa/evidence/release-check/level-010.png` 中可见四个灰蓝色半透明方块。
- **`design/audio.md` 与实现不一致**：设计仍要求 `scripts/tools/generate_sfx.py` 生成并提交 WAV（`design/audio.md:24-30`），实现已改为运行时合成（`src/audio/audio_director.gd:3-7`），`assets/audio/sfx/` 不存在。本 ticket 不修改设计文档。
- **`--screen=play` 不带 `--level` 会进第 1 关**：`_level_index = maxi(_boot_level_index, 0)`（`src/main.gd:170`），`SCREEN_GAMEPLAY` 分支直接 `_start_level(_level_index)`（`src/main.gd:708-709`）；需要指定关卡时传 `--level=<1..20|level-010>`。
- **没有商店素材、无签名**：仓库只有 `assets/data/` 与 `docs/screenshots/` 的截图，没有商店文案、胶囊图或宣传素材；Windows 构建没有代码签名证书，首次运行会触发 SmartScreen 警告（`design/release.md:105`）。
- **导出证据没有命令日志**：`production/qa/evidence/release-check/` 只有 3 张 PNG（`menu.png`、`level-010.png`、`zh-settings.png`），没有 `index.md` 或导出日志；导出与导出包启动的结果只能追溯到打包提交 `2d70c1b` 的说明，本 ticket 未复跑导出。

## Upgrade notes

- **首个发布**：没有旧版本可升级，也没有需要迁移的存档；存档 schema 当前为 `save_version` 1，位于 `user://save/profile.json`（`design/settings-and-save.md`）。
- **输入**：使用默认键盘/手柄绑定，可在设置页重映射；首个发布无绑定迁移。
- **引擎与平台**：Godot 4.7（本机验证于 4.7.2），GL Compatibility 渲染器，x86_64 的 Windows/Linux/Web 预设。
- **Web**：必须通过 HTTP(S) 提供（不能用 `file://`）；存档按 origin 隔离，换域名会丢失进度。
- **商店与签名**：没有商店素材与代码签名，见 Known issues；上架前需要人工补齐。
