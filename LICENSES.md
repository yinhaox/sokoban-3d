## Art and audio

- All geometry, materials, lighting and colours are generated by the project's
  own GDScript; there is no imported art.
- Sound cues are synthesised at runtime from the table in `src/audio/`; there
  are no audio files to license.
- Fonts are the engine's built-in font and the operating system's fonts. No
  font file is redistributed.

## Third-party code

The project vendors no third-party libraries. The `studio.py` helper uses only
the Python standard library; `tests/` uses only GDScript.
